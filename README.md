# NETFLIX_UI_CLONE 
Netflix UI Clone 🎬✨

This is a sleek and responsive Netflix UI clone, designed to replicate the look and feel of the popular streaming platform. Built with a modern tech stack, it features a dynamic homepage with smooth scrolling, engaging hover effects, and an intuitive layout that mirrors the original Netflix interface.

🔹 Features:
✔️ Eye-catching Hero Banner with trending content
✔️ Fully responsive grid layout for movies & shows
✔️ Hover effects for interactive previews
✔️ Dark-themed UI for a cinematic experience
✔️ Optimized for performance & smooth transitions
